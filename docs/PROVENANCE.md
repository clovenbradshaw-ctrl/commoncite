# Provenance and citation contract

## Witness before article

The original source is content-addressed before it is interpreted. The normalized witness stores its SHA-256, stable URI, preserved-copy path, media type, adapter receipt, EOReader revision, exact spans, and declared gaps.

## Passage addressing

The canonical locator form is:

```text
stable source URI + page or unit + byte-addressed EOReader span ID
```

The wiki may display a paragraph, concept page, definition, relationship, or overview. Every witnessed proposition must still resolve to the source-native passage beneath that projection.

## No copied authority

Article prose does not become a new witness merely because it repeats a source. Copies, transcripts, and transformations retain ancestry to the same source root.

## Self-grounding

A proposition without a resolvable external span may exist as testimony, argument, question, or analysis. It is grounded only in the event asserting it and receives zero independent witness weight.

## Concepts

A concept page is projected only when a referent passes minimum mention, frame, density, surface-coherence, and noise gates. Failure produces no page. A passed page is not proof that the engine's co-reference hypothesis is correct; it is a reviewable public hypothesis with visible surfaces and source trail.

## Definitions

Definitions are first-class, scoped statements. The deterministic gate recognizes explicit forms such as `means`, `defined as`, `refers to`, `defines … as`, dictionary-style colons, and carefully constrained copular definitions. Several definitions remain visible together. No global preferred definition is implied.
